# جرد البوفيه V1.1
برنامج مستقل عن برنامج المبيعات. يبدأ بـ29 صنفًا حقيقيًا موزعة على خمس فئات، دون أي صنف بلا فئة. جميع العبوات والكميات والأسعار فارغة.

## التشغيل
ارفع محتويات المجلد إلى GitHub Pages أو استضافة HTTPS. افتح index.html من رابط الاستضافة. يحتفظ البرنامج ببياناته محليًا في المتصفح؛ لا تمسح بيانات المتصفح دون تصدير نسخة احتياطية. المزامنة السحابية اختيارية وتحتاج مشروع Supabase منفصلًا، مع تنفيذ ملف supabase_schema.sql وضبط بيانات الاتصال من داخل التطبيق.

## وظائف
- سطر واحد لكل عبوة، اختيار العبوة، إدخال الكمية والسعر، حساب الإجمالي تلقائيًا، إضافة عبوة، وحذف سطر بتأكيد.
- الجرد السابق، المقارنة، تعديل جرد سابق، تصدير Excel، نسخ احتياطية.
- لا يوجد استيراد أصناف أو بيانات تجريبية في الواجهة.
- لا تتصل هذه النسخة بقاعدة بيانات البوفيه الأصلي.

## ملاحظة
هذه حزمة تنفيذ محلية مستقلة، لم يتم نشرها تلقائيًا على GitHub أو إعداد Supabase الخاص بها.


## تحديث V1.2 — صافي الربح
- تبويب مستقل لصافي الربح.
- قيمة المخزون من آخر جرد محفوظ (أو المسودة عند عدم وجود جرد محفوظ).
- بنود يدوية قابلة للجمع والطرح والإضافة والحذف: حساب الضباط، المحفظة، الكاش، الدين، رأس المال.
- تكلفة الضيافة للعرض فقط لأنها خُصمت بالفعل من قيمة المخزون، فلا تُطرح مرتين.
- الأرقام الافتراضية في شاشة الربح فارغة، ولا توجد أي صلة مالية ببرنامج البوفيه الأصلي.
- البيانات محفوظة محليًا مع الجرد، وتدخل ضمن النسخ الاحتياطية والمزامنة اليدوية الاختيارية.
- عند حدوث سحوبات شخصية أو إضافات رأس مال يجب تسجيلها يدويًا كبنود ملائمة.
